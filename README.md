# K2

Jeu de pixel art : escalade le K2 (8 611 m), seul face à la paroi. Mobile et bureau.

Production : https://supershivas.github.io/k2/

Commandes : boutons Gauche / Droite (ou ← → / flèches, touches physiques A D) à alterner ; maintenus, ils font marcher sur les pentes. Piton (Espace), Manger (E), O₂ (O), Camper (C), Sac (I, M, K). Plein écran, installable sur téléphone.

Aperçu dans un cadre de téléphone : https://supershivas.github.io/k2/apercu.html
